# Lab 4 - Required gameplay recordings

The assignment requires genuine 10-second recordings of the running game. These files are intentionally not generated as placeholders.

## before.mp4
1. Clone the original starter: `git clone https://github.com/SETAPESU26/48_whack-a-mole.git`.
2. Install dependencies and run the original game: `python -m pip install -r requirements.txt` then `python main.py`.
3. Start macOS screen recording (`Shift + Command + 5`) and record at least 10 seconds of the unmodified starter. Show the occasional double-score collision if it occurs; do not stage or fake it.
4. Save the clip as `before.mp4` in this `Lab-4` folder.

## after.mp4
1. Run this updated version with `python -m pip install -r requirements.txt` and `python main.py`.
2. Record at least 10 seconds showing normal play and one or more implemented features. For a complete demonstration, allow the timer to end, show the final score, then replay at a selected difficulty and demonstrate hit/miss sounds.
3. Save as `after.mp4` in this `Lab-4` folder.

## Before uploading
Confirm both files play and are approximately 10 seconds or longer. Include actual screen-captured gameplay, not a still image or synthetic placeholder.
